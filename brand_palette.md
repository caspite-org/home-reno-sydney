# Home Reno Sydney - Brand Color Palette

## Core Monochromatic Scale
The primary aesthetic is a warm, minimal monochromatic scale.

| Token | Hex Value | Usage |
|-------|-----------|-------|
| **Background** | `#F4F4F4` | Main page background |
| **Foreground** | `#111111` | Primary text, Headings |
| **Card** | `#FFFFFF` | Cards, Modals, Popovers |
| **Border** | `#E5E5E5` | Dividers, Borders |
| **Muted** | `#999999` | Secondary text, Captions |

## Renomate AI Accents
Renomate AI features are distinguished by a standard Blue accent palette (Tailwind Default Blue).

| Token | Hex Value | Usage |
|-------|-----------|-------|
| **Primary Accent** | `#2563EB` (Blue 600) | Buttons, Links, Highlights |
| **Secondary** | `#3B82F6` (Blue 500) | Icons, Decorations |
| **Subtle BG** | `#EFF6FF` (Blue 50) | Section backgrounds |
| **Light BG** | `#DBEAFE` (Blue 100) | Chips, Badges |
| **Dark BG** | `#1E3A8A` (Blue 900) | Contrast sections (Footer/CTA) |
| **Text Light** | `#DBEAFE` (Blue 100) | Text on Dark Blue BG |

## UI & Precision Elements
Used for the fine grid lines, circles, and technical details.

| Token | Value | Usage |
|-------|-------|-------|
| **Grid Line** | `rgba(17, 17, 17, 0.08)` | Background patterns |
| **Circle Border** | `rgba(17, 17, 17, 0.08)` | Decorative precision circles |
| **Scrollbar** | `#D4D4D4` | Scrollbar thumb |
| **Scrollbar Hover** | `#A0A0A0` | Scrollbar interaction state |
